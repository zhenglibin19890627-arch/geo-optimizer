# GEO 优化系统（使用说明·大白话版）

这个系统帮你做一件事：**让豆包、DeepSeek、Kimi、通义千问、腾讯元宝（混元底座）等 AI 引擎在回答用户问题时，更多地提到你的品牌，并且提到时位置靠前、评价正面。**

---

## 一、开始使用（只需 3 步）

### 第 1 步：安装 Python
1. 去 Python 官网 https://www.python.org/downloads/ 下载并安装（Windows 版）。
2. **安装时一定要勾选「Add Python to PATH」（把 Python 加入系统路径）**，不然后面命令会提示找不到 python。

### 第 2 步：一键安装依赖
打开「终端」（Windows 里叫 PowerShell 或 CMD），进入本项目文件夹，执行：

```
pip install -r requirements.txt
```

看到类似 `Successfully installed ...` 就说明装好了。

### 第 3 步：一键启动
接着执行：

```
python app.py
```

程序会自动打开浏览器（地址一般是 `http://127.0.0.1:5080`，如果 5080 端口被别的程序占用，会自动换成 5081~5090，提示里会写明）。

## 二、第一次使用要做什么

1. **填品牌信息**：在「设置」页填写品牌名、产品名、竞争对手名单（可选）。
2. **填各家 AI 平台的钥匙（API Key）**：
   - 在「设置」页的「各家 AI 的模型配置」卡片里，直接粘贴钥匙（API Key）点「保存钥匙」即可，**保存后立即生效，不用重启**；
   - 钥匙也可以在 `config/config.yaml` 里手动填（程序第一次启动会自动生成该文件）；
   - 填好后在设置页点「测试一下」，检查钥匙是否可用。
3. **发起第一轮监测**：到「监测中心」选好问题和引擎，点「开始监测」，等几分钟就能看到结果。

### 各家平台的钥匙去哪拿（大白话）

## 三、几个大白话概念

| 词 | 是什么意思 |
|----|-----------|
| 提及率 | 一轮监测里，AI 回答中提到你的问题，占所有问题的比例 |
| AI 可见度评分 | 综合提及率、评价好坏、被提到时排第几等算出来的 0-100 分 |
| 引用信源 | AI 回答时引用的网站来源，看它从哪些渠道获得信息 |
| 净情感率 | 正面评价占比减负面评价占比，-100%~100% |
| 钥匙（API Key） | 各家 AI 平台给你的“访问凭证”，填错了就调不通 |

## 四、每天自动监测

- 默认每天 **08:30** 自动监测一轮（这个时间避开了 DeepSeek 高峰加价时段）；
- 时间、开关都可以在「设置」页改；
- **想让系统每天自动监测，请保持本程序开着（可以最小化窗口，但不要关掉它）**；
- 程序没开的时段错过了也没关系：下次启动时如果发现距上次成功监测超过 26 小时，会自动补跑一轮。

## 五、常见问题

**问：不填钥匙能用吗？**
答：能启动、能看界面。监测和优化建议需要钥匙才能调用 AI；但「手动粘贴」通道永远可用——把 AI 的回答粘进来，系统照样帮你分析提到没有、评价好坏、引用了哪些网站。

**问：钥匙填错了会怎样？**
答：设置页点「测试一下」会告诉你“钥匙不对或已失效”。监测发起时也会先检查，没填的引擎会提示你先去设置页。

**问：一轮监测要多久、多少钱？**
答：默认 10 个问题 × 5 家引擎 = 50 次调用，约 8-15 分钟，费用约 1-2.5 元（具体以平台账单为准，设置页能看到“本月大概花了多少钱”）。模型档位可以在设置页切换，选便宜的档能省钱。

**问：网页内容分析失败怎么办？**
答：有些网站禁止程序读取（robots.txt 禁止）或是动态页面。改用「粘贴文字」方式把内容粘进来就行。

**问：数据存在哪里？**
答：全部存在本地 `data/geo.db`，钥匙存在本地 `config/config.yaml`，不会上传到任何地方。

## 七、开机自启与系统托盘（推荐的使用方式）

想让系统**开机自动运行**，并且随时在**系统托盘**里管理它，用这个方式：

### 1. 启动托盘

```
pythonw tray_app.py
```

（在文件夹里双击 `tray_app.py` 也一样。托盘程序会先把后台服务拉起来，然后屏幕右下角系统托盘会出现一个蓝色 **G** 图标。）

### 2. 托盘菜单能干什么

| 菜单 | 作用 |
|------|------|
| 打开界面 | 在浏览器打开系统页面（双击图标同样效果） |
| 暂停服务 / 启动服务 | 停止 / 重新拉起后台服务（页面和每日自动监测随服务一起停/开） |
| 重启服务 | 重启后台服务（配置、钥匙改动后兜底刷新） |
| 开机自启 | 勾上后，下次开机自动在托盘运行（写当前用户注册表，不需要管理员权限） |
| 退出 | 关掉托盘并停止后台服务 |

> 提示：
> - 「暂停服务」期间系统页面打不开、每日自动监测也不会跑；点「启动服务」恢复，之前的数据都在。
> - 托盘同一时间只会有一个：重复启动会自动退出。
> - 后台服务的日志写在 `data/service.log`，服务起不来时可打开看看原因。

### 3. 开机自启的原理

「开机自启」开关写的是注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，只对当前用户生效、不需要管理员权限；关掉开关即删除该项，不残留任何文件。
