## 五、数据与费用处置

- 共享库 `data/geo.db` 测试期间零污染（SHA256 与备份一致）
- 真实 API 调用费用：首轮 ≤0.02 元 + 二轮 0.022 元 + 三轮 0.0275 元，合计约 0.07 元
- 隔离副本/全新库保留在系统临时目录备查；测试后已停止服务、无残留进程
- 测试产生的部分数据保留在共享库中以备复现（如需全新状态：删除 data/geo.db 后重启即可）
